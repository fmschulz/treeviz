# Use TreeViz In The Browser

TreeViz is a static browser app for loading, editing, annotating, and exporting
phylogenetic tree figures.

## Open The App

Production app:

```text
https://treeviz.newlineages.com/
```

Programmatic API mode:

```text
https://treeviz.newlineages.com/?api=1
```

Render-only automation mode:

```text
https://treeviz.newlineages.com/?mode=headless&api=1
```

## Load Data

TreeViz accepts:

- Newick and Nexus tree files.
- `.treeviz.json` sessions.
- TSV/CSV metadata tables with one header row.

Metadata row keys are matched to tree leaf labels by default. Use the metadata
review step to choose a different row-key column or normalization behavior.

## Export Work

Use `.treeviz.json` to preserve tree edits, metadata, tracks, view settings,
and saved views. Use SVG/PNG/PDF exports for figures, and Newick/Nexus/metadata
exports for downstream data exchange.

## Public Machine-Readable Files

The deployed app publishes:

- `/version.json`
- `/treeviz-command-schema.json`
- `/treeviz-session.schema.json`
- `/examples/manifest.json`

Use the session schema to validate `.treeviz.json` files generated by wrappers
or external pipelines before opening them in TreeViz.
