# Examples

TreeViz ships browser examples under `public/examples/` and wrapper examples in
this directory.

## Browser Examples

The browser example catalog is generated by:

```bash
bun run examples:emit
```

The deployed manifest is available at:

```text
https://treeviz.newlineages.com/examples/manifest.json
```

## Python Notebook

[python-notebook.ipynb](python-notebook.ipynb) builds a TreeViz session from a
pandas `DataFrame`, validates it, saves it, displays the interactive TreeViz
iframe with `display(view)`, and renders PNG/SVG exports. The saved session and
inline view use the same metadata tracks and view settings.

Run it through Pixi:

```bash
pixi run -e py py-notebook
```

For interactive use on `nb.newlineages.com`, select the `Python (Pixi)` kernel.
For local interactive use, launch Jupyter through Pixi:

```bash
pixi run -e py jupyter lab docs/examples/python-notebook.ipynb
```

or install the named kernel with `pixi run -e py py-kernel` and select
`TreeViz (pixi py)`.

For a repo-local kernelspec under `share/jupyter/kernels/treeviz-py`, use:

```bash
pixi run -e py py-kernel-local
pixi run -e py py-jupyter-local
```

## Python Script

The package-facing script at `examples/plot_treeviz_examples.py` imports
`treeviz`, builds two example trees with metadata tracks, validates metadata
binding, writes `.treeviz.json`, and renders auto-cropped SVG/PNG/PDF outputs
plus crop metrics through the TreeViz CLI when a renderer is available.

Run it after installing the package:

```bash
python examples/plot_treeviz_examples.py --out /tmp/treeviz-python-plots
```
